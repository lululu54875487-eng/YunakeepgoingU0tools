關於下載與內容長度的小提醒 ＋

支援的瀏覽器會開啟「另存新檔」視窗；其他瀏覽器會依下載設定儲存圖片，可能直接下載。手機也可使用檔案預覽中的分享或儲存功能。網站無法強制每個瀏覽器顯示相同的儲存對話框。

單張 QR Code 有容量限制：本工具支援最多 2,953 個 UTF-8 bytes，中文與 emoji 通常占多個 bytes。超過時會提示縮短內容。文字越短，QR Code 越容易掃描。前後空白與換行會原樣保留。
